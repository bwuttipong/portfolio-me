# Wuttipong Thongmon — Portfolio

Personal portfolio site. Built with React + Vite.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm run preview
```

## Deploy

Output is in `dist/`. Drop on any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages).
